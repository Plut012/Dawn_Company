2. Lobby, live

Three real clients against the real server, each in its own slot (?slot=a, b, c), so each keeps its own seat. The first is phone-sized (390 × 844).

  1. Type a name in each frame and press Join. Each frame lists all the seats as they arrive.
  2. Build squads: press − and + on a unit, press a section key (Line, Weapons, Scout), and use the ▲ ▼ keys to reorder. Make a squad illegal (fewer than 4 units): the report turns Rust and the lever locks.
  3. Throw the lever in each frame. The first frame (the host) gets a live Start key once all three are ready. Changing a squad while ready pops the lever back up.
  4. Press Start. All three frames land on the placeholder play screen with the round and unit count.
After a match has started, the server only takes returning tokens. For a fresh lobby, stop and restart npm run server, then press Forget seats.

3. Reconnect

  1. Reload a frame (the Reload keys under each frame). It takes its seat back: same name, same squad, same ready lever, the other frames never see it leave for long.
  2. Stop and restart the server (Ctrl-C, then npm run server). Every frame shows the Rust "Signal lost" strip and a blinking lamp, retries by itself, and when the server is back it joins again. A restarted server has an empty room, so in the lobby each frame comes back as a new seat in the same order (with the first squad preset); mid-match the old tokens are unknown and the server refuses them with an error.
  3. Open the same slot in two windows. The older one is told "This seat is open in another window".
Observed when this was built (headless Chromium, three clients):

Reload: a reloaded frame rejoined with its token and was back in the same seat, name and squad within about a second; the other frames kept showing it as present.
Server stopped: each frame showed the Rust "Signal lost" strip and "No signal" lamp within a second or two.
Server restarted: the strips cleared within about five seconds (back-off 0.25 s up to 3 s). In the lobby the frames came back as new seats, in whatever order they reconnected (so the host can change), each with the first preset squad.
Late joiner after Start: told "The match has started…" in the Rust strip; the join form stays.
Closed a window in the lobby: its lamp went Rust ("lost signal") and, after the server's 30 s grace, its seat was freed and the rest renumbered.
