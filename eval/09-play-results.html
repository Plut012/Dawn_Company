Eval 09 — Play and results screens

Needs npm run server (port 8080) and npm run dev. The two frames below are the real client (/?slot=a and /?slot=b) against the real server: one laptop-shaped, one phone-shaped (390 × 844). One person can play a whole match from this page. Nothing here is mocked; the only help the page gives is the keys in the bar under the frames.

For the timer line of the checklist, run the server with a short timer: npm run server -- --timer 30. With the default 90 seconds everything else is easier to try. A third seat (to see a squad go out and keep watching) is one more tab at /?slot=c, joined before the host presses Start.

1. Play it

Join in both frames (any names), throw both ready levers, press Start in the left frame (the host).
